Quick Tutorial

1. Click anywhere to create P1.
2. Move the pointer. The live length + angle appear automatically.
3. Simply click for normal grid-snapped drawing.
4. Type a number while moving the pointer to lock the length.
5. Type an angle followed by A to lock the exact angle.
6. Press Enter to create the line.
7. F8 = exact horizontal/vertical.
8. F10 = polar tracking.
9. Parallel / Perpendicular can lock the line relative to an existing boundary.
10. Return to P1 to close the plot.
11. D toggles dimensions.
